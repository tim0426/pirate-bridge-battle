# Pirate Bridge Battle / 海盜獨木橋對戰

Open `index.html` in a browser, or run `python3 -m http.server` from this `game/` folder and visit the local URL. Two players share one screen (phone or computer). Works with touch.

Tap a card, then a green cell on your half. Left places first, taps **DONE**, and passes the device. Right places, then taps **ADVANCE** to resolve the turn.

**Ranged stays on your half and can only shoot up to the midline.** Cannon can still strike the enemy half. First ship to 0 HP loses.
